# نظام إدارة أسطول حافلات النقل ومتابعة السائقين
### مؤسسة سويقات أبو طالب لنقل المسافرين والرحلات

تطبيق Flutter متكامل وعصري لإدارة ومتابعة أسطول الحافلات (سعة 50 راكب وغيرها)، تسجيل ومتابعة الرحلات اليومية، تنظيم حضور السائقين بالتقويم الميلادي وطرق العمل المختلفة، وحساب وطباعة كشوف الأجور الشهرية والأجر الإضافي بالدينار الجزائري (دج).

---

## ✨ المميزات الرئيسية للمشروع

1. **🎨 تصميم أنيق باللونين الأزرق والأبيض (Blue & White Palette):**
   - واجهة مستخدم متناسقة ومريحة للعين مع دعم كامل للغة العربية واتجاه اليمين لليسار (RTL) وخط Cairo.
   - بطاقات مؤشرات أداء بيضاء نقية مع ظلال زرقاء خفيفة وتدرجات ملكية.

2. **📅 التقويم الميلادي وخيارات السائقين:**
   - شريط سريع وتفاعلي لاختيار السائقين وقائمة مخصصة لكل سائق.
   - متابعة أيام الحضور، أيام الراحة الدورية، الغياب، والساعات الإضافية.
   - إمكانية الضغط على أي يوم في التقويم لتعديل الحالة يدوياً أو إضافة ساعات إضافية وملاحظات.

3. **🔄 أنظمة وطرق العمل الأربعة (Work Shift Patterns) مع الملء التلقائي:**
   - **يوم عمل / يوم راحة (1:1):** مناوبة متناوبة بالتساوي.
   - **يوم عمل / يومان راحة (1:2):** يوم عمل يليه يومان راحة.
   - **شهر عمل مستمر:** عمل كامل طوال الشهر مع عطلة الجمعة.
   - **يومان عمل / يوم راحة (2:1):** يومان عمل يليهما يوم راحة.
   - **زر الملء التلقائي (Auto-Fill):** توليد تقويم الشهر بضغطة زر واحدة وفق النظام المختار.

4. **🚌 إدارة الأسطول وسجل الرحلات والأجر الإضافي:**
   - متابعة حافلات 50 مقعد ونسب إشغال المقاعد ومعدلات الامتلاء.
   - استبدال الوقود بالأجر الإضافي للسائقين لتشجيع الإنتاجية ومكافأة المسافات الطويلة.
   - تسجيل رحلة جديدة مع احتساب فوري لنسبة الإشغال والمستحقات.

5. **🖨️ كشوف الأجور وطباعة التقارير الشهرية لكل سائق:**
   - احتساب الراتب الأساسي + حوافز الرحلات + الأجر الإضافي + المكافآت - الخصومات.
   - إمكانية طباعة كشف الراتب الرسمي الشهري وتصديره مباشرة.

## 🚀 كيفية التشغيل (How to Run)

### المتطلبات الأساسية
- Flutter SDK (3.x أو أحدث)
- Dart SDK
- محاكي أندرويد أو جهاز متصل أو Chrome للويب

### أوامر التثبيت والتشغيل
```bash
# تثبيت الحزم
flutter pub get

# تشغيل التطبيق
flutter run
```
